A one-line 1-star review written by a houseplant about the human who owns it — repotted into a pot with no drainage, blamed for the flood, while the carpet got the apology.

## Run it

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` (1–279 characters, one line, standard library only).
